# Survivors HUD для браузерной версии

В этой папке лежит готовый архив для браузерной версии [Azeroth Survivors](https://wow.aethus.pl/). Распаковывать его не нужно.

**[Скачать nfUI-survivors-edit.zip](https://github.com/Notker367/nfui-survivors-edit/raw/main/web/nfUI-survivors-edit.zip)**

## Установка

1. Скачайте архив по ссылке выше.
2. Откройте игру в браузере: нужен браузер с WebGPU, например актуальный Chrome, Edge или Safari.
3. Перейдите в **Настройки → AddOns → Install AddOns** и выберите скачанный файл.
4. Начните новый забег: аддон загрузится с него.

Для обновления выберите новый архив тем же способом: он заменит старую версию. Удалить аддон можно на той же странице кнопкой **Remove**.

## Что важно знать

- Аддон хранится только в этом браузере. На другом устройстве, в другом браузере или после очистки данных сайта его нужно ставить заново.
- Раскладка сама подстраивается под размер окна и масштаб интерфейса. Если что-то встало неудобно, панели можно подвинуть через `/nfui` → **Movers**.
- При первом запуске раскладка заменит прежнюю настройку nfUI.

## Что проверено

Установка проверена в Chromium кодом установщика игры (`addons.js`): аддон ставится, все файлы из `nfUI.toc` на месте, после перезагрузки страницы он сохраняется, повторная установка не создаёт дубль.

Забег проверен в Edge: аддон работает. В браузере мини-карта квадратная, без мягкого края: браузер не загружает такую маску. Если появится окно с ошибкой, напишите в ветке в Discord игры, где нашли эту сборку, и приложите скриншот.

Архив собран из этого же репозитория, версия 1.3.0.
