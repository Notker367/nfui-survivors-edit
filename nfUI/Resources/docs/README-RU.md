# nfUI, правленая версия для Azeroth Survivors

Неофициальная доработка аддона nfUI. Авторы исходного кода указаны в `Resources/licenses/`.

## Установка
1. Распакуй архив: папка `nfUI` должна лежать прямо в `benilla-config/AddOns`.
2. Если nfUI уже стоял, сначала удали старую папку `nfUI`.
3. Включи аддон в списке AddOns и начни забег.

## Если что-то не так
- Раскладка настроена на экране 3440x1440. На другом разрешении панели могут стоять иначе: подвинь их через `/nfui`, кнопка Movers.
- При первом запуске раскладка заменит твою прошлую настройку nfUI.
- Чтобы убрать правки, удали папку и поставь обычный nfUI.

## Что изменено
Панели героя и цели с живыми портретами, блоки скилов с рангом и DPS, предметы и пул скилов, панель DPS группы с лучшим скилом, полоски врагов и союзников с цветами по рангу и классу, щит внутри полоски здоровья, короткие цифры урона со значками, значок сундука, цель цели, блокировка панели скилов, исправления ошибок Font not set и переполнения стека.
